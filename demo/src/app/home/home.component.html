@wbd/editor — Demo

Angular PDF editor with annotation tools and digital signature support (CAdES). This app wires up the library with demo providers so you can try it without a backend.

Open a document in the editor The demo stores the document in localStorage and navigates to /editor, where the <wbd-editor> component renders it inside a PDF.js viewer. or

Once the editor opens, use the toolbar above the document: pen, highlight, rectangle, line, text, comment and signature / stamp placeholders. Switch back to the cursor tool to move annotations; double-click one to delete it.
